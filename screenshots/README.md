## Generating Screenshots

To generate actual screenshots:

1. Start the server:
   ```bash
   npm start
   ```

2. Open the dashboard at `http://localhost:3000/dashboard`

3. Use browser DevTools or a screenshot tool to capture each view

4. Save images as PNG (1280×720 recommended) in this directory

5. Update the README.md references accordingly
